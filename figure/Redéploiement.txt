  Redéploiement 
  
  Si tu veux relancer le déploiement Azure après avoir travaillé en local, fais l’inverse de l’arrêt.

D’abord, remets les services Azure disponibles :

1. PostgreSQL Azure → Start
2. Backend Container App → ingress ON
3. Frontend Container App → ingress ON

Tu peux garder min replicas = 0, ce n’est pas bloquant.

Ensuite reconnecte Azure CLI dans Jenkins si la session a expiré :

docker exec -it matchia-jenkins az login --use-device-code

Puis vérifie :

docker exec matchia-jenkins az account show

Après ça, relance ton tunnel Cloudflare :

cloudflared tunnel --url http://localhost:8080

et vérifie que le webhook GitHub est toujours Active.
